- 🏗️ **Now:** leading the evolution of **Workforcenexa** at D4 Insight, from an AI recruitment tool into a full HRMS, Finance and Employee Self-Service platform
- 🤖 **Focus:** multi-agent orchestration, RAG, Intelligent Document Processing, and the AI-Driven Development Lifecycle (AI-DLC)
- 🏦 **Background:** banking and fintech UIs (Modern Banking Platform, CAPE reporting) with multi-tenant, multi-currency requirements
- ⚡ **How I work:** AI-assisted delivery with Claude, Codex and GitHub Copilot, with humans approving every stage

## What I've been building

**Workforcenexa** (D4 Insight, private)
- Multi-agent architecture: specialised agents for recruitment screening, HR case resolution, finance approvals and employee self-service, coordinated by a central orchestrator
- Micro-frontends (Module Federation) and microservices across People, Finance, Auth and Recruitment domains (React, FastAPI, PostgreSQL, AWS EC2)
- Centralised auth with role-based access control for multi-tenant use
- LLM-powered resume parsing, candidate matching and document workflows

**AI-DLC App Builder.** Describe an app in one sentence and build it with AI stage by stage: requirements, design, streamed code generation, then a live preview. Every stage needs human approval, and requirement IDs trace through to the code. Built with FastAPI, React + TypeScript, Claude, SSE and Docker.
